# Figma/FigJam import notes

The architecture diagram is already prepared in SVG format at [docs/lair-athletics-architecture.svg](docs/lair-athletics-architecture.svg).

## Import options

1. Open FigJam or Figma.
2. Create a new board or file.
3. Drag and drop [docs/lair-athletics-architecture.svg](docs/lair-athletics-architecture.svg) into the canvas.
4. If the SVG imports as a single image, use it as a reference layer and recreate the board using the provided layout notes in [docs/figjam-board-outline.md](docs/figjam-board-outline.md).

## Recommended board structure

- Frame 1: Overview architecture
- Frame 2: User flow
- Frame 3: Storage options
- Frame 4: Module map
